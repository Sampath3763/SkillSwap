You are a senior full-stack engineer and product architect.

Build a complete, production-ready web application named "SkillSwap".

SkillSwap is a non-monetary local skill exchange platform where users trade skills instead of money.
Example:
- "I will teach Python in exchange for resume review"
- "I will repair phones in exchange for logo design"

====================
CORE REQUIREMENTS
====================

1. TECH STACK
- Frontend: React (with modern UI, responsive design)
- Backend: Node.js + Express
- Database: MongoDB (or Replit DB if Mongo is unavailable)
- Authentication: Email/password with JWT
- Deployment-ready inside Replit (one-click run)

====================
USER FEATURES
====================

2. USER AUTHENTICATION
- Sign up / Login
- User profile with:
  - Name
  - Location (city)
  - Skills Offered (multiple)
  - Skills Wanted (multiple)
  - Availability (online / offline / both)
  - Bio
- Profile edit option

3. SKILL LISTING SYSTEM
- Users can:
  - Add skills they offer
  - Add skills they want
- Each skill should have:
  - Skill name
  - Level (Beginner / Intermediate / Expert)
  - Mode (Online / Offline)
- Skills must be searchable and filterable

4. MATCHING & EXCHANGE LOGIC
- Match users based on:
  - Skill A offered by User 1 = Skill wanted by User 2
  - Skill B offered by User 2 = Skill wanted by User 1
- Show “Potential Skill Swaps” dashboard
- Allow users to send a Skill Swap Request
- Request states:
  - Pending
  - Accepted
  - Rejected
  - Completed

====================
TRUST & REPUTATION
====================

5. SKILL CREDITS SYSTEM
- Every user starts with a base number of Skill Credits
- Credits are earned by:
  - Completing a skill exchange
  - Receiving positive feedback
- Credits are required to initiate new swap requests
- Prevent spam and fake users

6. COMMUNITY-VERIFIED REPUTATION
- After a completed exchange:
  - Both users must rate each other (1–5)
  - Leave feedback
- Display:
  - Average rating
  - Number of completed swaps
- Reputation affects visibility in search results

====================
VIRTUAL MEET FEATURE
====================

7. ONLINE MEETING INTEGRATION
- Include a virtual meeting option for online learning
- Generate a unique meeting link per accepted swap
- Use:
  - WebRTC (preferred) OR
  - Jitsi Meet / Daily / basic video call integration
- Meeting should support:
  - Video
  - Audio
  - Chat
- Meeting link visible only to matched users

====================
UI / UX REQUIREMENTS
====================

8. DASHBOARDS
- User Dashboard:
  - Active swap requests
  - Skill credits balance
  - Upcoming meetings
- Clean, modern UI
- Mobile responsive

9. NOTIFICATIONS
- Notify users when:
  - Swap request is received
  - Swap is accepted/rejected
  - Meeting is scheduled
- In-app notifications (no email required)

====================
SECURITY & QUALITY
====================

10. SECURITY
- Protect private routes
- Validate inputs
- Prevent unauthorized access to meetings

11. CODE QUALITY
- Clean folder structure
- Reusable components
- Clear comments
- Environment variables for secrets

====================
DELIVERY
====================

12. FINAL OUTPUT
- Fully functional application
- Runs inside Replit
- Ready to deploy
- Include:
  - README.md with setup instructions
  - Sample test users
- Do NOT leave placeholder logic
- All features must work end-to-end

Build SkillSwap as a real-world usable application, not a demo.
