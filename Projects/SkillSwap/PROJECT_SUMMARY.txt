🚀 QUICK START (3 STEPS):

  Step 1: Install & Start Backend
    $ cd server
    $ npm install
    $ npm start
    → Server running on port 5000

  Step 2: Install & Start Frontend (new terminal)
    $ cd client
    $ npm install
    $ npm start
    → App opens at http://localhost:3000

  Step 3: Seed Sample Users (optional, new terminal)
    $ cd server
    $ node scripts/seedDatabase.js
    → Database populated with 5 test users

🚀 DEPLOYMENT OPTIONS:

  Local Development
    → Just run `npm start` in both folders
    → Uses local MongoDB

  Docker
    → `docker-compose up --build`
    → All-in-one setup with MongoDB

  Heroku
    → `heroku create` + database addon
    → `git push heroku main`
    → See README.md for details

  Replit
    → Import from GitHub
    → Set `.env` with MongoDB Atlas URI
    → Click "Run"

  VPS (AWS, DigitalOcean, etc.)
    → Standard Node.js deployment
    → Use MongoDB Atlas for database
    → Use PM2 for process management
